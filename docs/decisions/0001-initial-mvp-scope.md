# Decision 0001 — Initial MVP Scope

Status: accepted

AGym v0 starts with the Unstructured Logger + Coach Briefing Generator.

The first useful vertical slice is:

```text
raw text log → parsed JSON → editable preview → user confirmation → canonical event saved locally → Coach Briefing markdown → JSON export
```

This repository begins with documentation/specification only. App code should be added issue-by-issue after the source-of-truth docs have been reviewed.
