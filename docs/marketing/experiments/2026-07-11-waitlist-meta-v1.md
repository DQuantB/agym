# Experiment — AGym waitlist / Meta v1

Status: internal preparation. No external activity or performance data exists.

## Question

Can the message `Stop re-explaining your fitness history to AI.` convert AI-native fitness users into qualified waitlist signups?

## Hypothesis

People who already use AI for fitness will recognize repeated context reconstruction as a painful problem and respond to a local-first data/memory-layer framing.

This is a hypothesis. It has not been tested.

## Constant variables for the first test

- One landing page and one waitlist form.
- One audience hypothesis: people already using AI for training, nutrition, or self-improvement.
- Historical v1 visual system: black-and-white instructional manga (retired before publication).
- Current v2 visual-system hypothesis is documented separately in `2026-07-11-performance-interface-v2.md`.
- One conversion event: completed waitlist signup.
- One disclosure posture: AGym v0 is being built, local-first/browser-based intent, and not medical software.
